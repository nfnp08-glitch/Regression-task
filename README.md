# Regression-task
Прогнозирование стоимости медицинского страхования!

## Описание проекта
Этот обучающий проект наглядно демонстрирует все этапы решения классической задачи регрессии в Data Science — от первичного анализа данных и предобработки признаков до подбора моделей, борьбы с дисбалансом классов и оценки качества.

## Цель
Цель проекта — на практике отработать полный цикл решения регрессионной задачи в Data Science: от анализа исходных данных и предобработки признаков до выбора и сравнения моделей, подбора способов борьбы с дисбалансом классов и интерпретации результатов.

## Задачи

Файл EDA.ipynb — база и первичный анализ:
* проверка качества данных и аудит на ошибки;
* изучение распределения признаков и таргета, анализ взаимосвязей;
* препроцессинг: обработка пропусков, кодирование категориальных переменных, унификация типов.

Файл baseline_tuning.ipynb — улучшения и валидация:
* построение базовой модели и расчёт метрик — фиксация стартового уровня качества;
* тестирование преобразований данных и новых признаков;
* оценка эффективности через кросс‑валидацию;
* отбор только тех улучшений, которые стабильно повышают метрики.

## Для кого
Проект носит обучающий характер — его цель не в достижении максимальной точности любой ценой, а в системном освоении типовых шагов и распространённых подводных камней при построении классификационных моделей.

## Заключение

В рамках проекта была решена задача прогнозирования годовых медицинских расходов клиентов. Для этого был реализован полный цикл построения ML‑решения: от разведочного анализа данных (EDA) и подготовки признаков до подбора гиперпараметров, обучения моделей и интерпретации результатов.

Был проведён сравнительный анализ нескольких моделей регрессии, включая Ridge Regression (в качестве бейзлайна), Decision Tree и LightGBM. Подбор гиперпараметров для каждой модели выполнялся с помощью кросс‑валидации (5 фолдов), а целевая переменная предварительно подвергалась логарифмическому преобразованию (log1p) — это позволило стабилизировать дисперсию и улучшить качество прогноза на данных с длинным правым хвостом.

Наилучшие результаты показала модель LightGBM: на отложенной тестовой выборке достигнуты следующие метрики качества — MAE = 964.04, RMSE = 1677.09, R² = 0.693, MAPE = 51.68 %. Высокий коэффициент детерминации (R² = 0.693) свидетельствует о том, что модель успешно улавливает основные закономерности, определяющие уровень расходов, несмотря на значительную вариативность целевой переменной и влияние редких, плохо предсказуемых событий. Умеренное превышение RMSE над MAE подтверждает наличие отдельных крупных отклонений — это типично для распределения медицинских расходов и не говорит о переобучении, а отражает естественную структуру данных.

С точки зрения практической применимости модель демонстрирует сбалансированную точность прогноза: средняя абсолютная ошибка в 964 единицы позволяет использовать предсказания для планирования и бюджетирования, а значение R² на уровне 0.693 подтверждает, что значительная часть изменчивости расходов объясняется моделью. При этом относительно высокий MAPE (51.68 %) обусловлен структурой распределения: процентная ошибка особенно чувствительна к низким значениям целевой переменной, поэтому для оценки качества прогноза приоритет отдаётся MAE и RMSE.

Важным наблюдением стало то, что ансамблевые методы на основе деревьев (LightGBM) существенно превосходят линейные модели (Ridge) в задачах с нелинейными зависимостями и сложными взаимодействиями признаков. Линейная модель, хотя и остаётся полезной для интерпретации базовых эффектов, не способна адекватно аппроксимировать пороговые эффекты и неоднородности в данных о расходах.

На основании полученных результатов в качестве финальной модели для прогнозирования медицинских расходов рекомендуется использовать LightGBM с подобранными гиперпараметрами. Параметры модели (умеренная глубина дерева, низкая скорость обучения, прореживание признаков и объектов, ограничение на минимальный размер подгруппы) обеспечивают баланс между выразительной способностью и устойчивостью к переобучению, что делает её оптимальным выбором для практического применения.
